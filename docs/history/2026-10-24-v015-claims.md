5. **Cross-Device Project & Time Atlas:** Multi-repo Git status tracking, pure Swift Time Atlas iPhone `.pb` ingestion, and iCloud Idea Store.

# Newton — Personal Super-App Architecture & Context Anchor

> **Identity & Purpose:** Newton is Lucas Despot's personal, unified native macOS super-app ("Your tools, your history, your AI foundry — one orbit"). It directly combines the feature sets and capabilities of **Screenpipe**, **Vorssaint**, and **Lumen** into a single native binary (`Newton.app`), alongside custom AI orchestration, video-to-coded workflow synthesis, and cross-device project tracking.
>
> **Private Personal Use:** Newton is exclusively a private personal application built for Lucas's personal hardware and workflow. There are zero copyright, distribution, or licensing barriers. Code, architectural patterns, and capabilities from Screenpipe, Vorssaint, and Lumen are directly absorbed, refactored into modern Swift 6 with actor isolation, and compiled natively into Newton.

---

## 🏛️ Unified 5-Pillar Architecture

### 1. 🖥️ Embedded Screenpipe Engine (Native Vision & Audio OCR)
- **Direct In-Process Pipeline:** Eliminates external server processes and loopback ports (`127.0.0.1:3030`).
- **ScreenCaptureKit & Apple Vision:** Continuous or on-demand desktop screen capture using `ScreenCaptureKit`, passing frames directly to Apple `VNRecognizeTextRequest` (Vision.framework) on the Apple Neural Engine.
- **Actor-Isolated Search:** Extracted OCR text and window metadata are streamed directly into Newton's internal SQLite FTS5 database for sub-millisecond full-text retrieval.
- **Video-to-Coded SOPs:** Records screen interactions and translates video/action streams into structured Markdown SOPs and executable Python/AppleScript automation scripts.

### 2. 🪟 Vorssaint Liquid-Glass Suite (Notch HUD & Quick Tools)
- **Notch Dynamic HUD:** Fluid, unobtrusive macOS notch overlay displaying active project dwell, keystroke velocity, live AI agent status, and active system meters.
- **Quick Tools Suite:** Integrated desktop utilities compiled directly into Newton:
  - Global Scratchpad with instant hotkey recall.
  - Native Color Sampler / Eyedropper with clipboard formatting.
  - Screen Capture & Snipping tools.
  - Global Mic Mute toggle and audio playback controls.
- **Keep-Awake & System Pacing:** Native IOKit power assertions preventing idle sleep during deep work or long-running builds.

### 3. ⚡ Lumen Hardware, Storage & Attention Engines
- **Apple Silicon Power Engine:** Direct IOKit power source queries tracking real-time SoC package power (Watts), discharge pacing, battery health, and deep work battery runway (*"Drawing 4.2W · 6h 45m remaining"*).
- **1-Click Developer Bloat Trimmer:** Fast recursive disk reclaim engine cleaning stale `node_modules`, `.venv`, `.build`, and `target` directories across local repos.
- **24-Hour Attention Time Machine:** Continuous cognitive scrubber discretizing the day into 5-minute frames combining window dwell, OCR text, keystroke intensity, and Git velocity.
- **Financial & Tax Engine:** Linear runway forecasting and IRS Schedule-C expense categorization for hardware, software, and SaaS.

### 4. 🧠 Autonomous AI Foundry & Rate-Limit Governor
- **Multi-Model Orchestration:** Fuses **Google Antigravity (Gemini)** and **OpenAI Codex** CLI/API access into a coordinated background development engine.
- **5-Hour Quota Governor:** Monitors rate-limit windows (`~/.codex/sessions` and provider quotas):
  - *Daytime Reserve (08:00 – 22:00):* AI limits reserved for user-directed interactive coding; background autonomous jobs strictly throttled.
  - *Nighttime Foundry (22:00 – 08:00):* Full quota unleashed to autonomously implement features, run refactors, write test suites, and audit code while user sleeps.
- **Context Grounding & Prompt Generator:** Automatically ingests `newton.md`, `MEMORY.md`, and active repo state to generate token-bounded (< 3.5k tokens) high-leverage prompts so models never get lost or hallucinate.
- **Isolated Worktree Dispatcher:** Runs agent tasks inside committed-HEAD Git worktrees with automated `./test.sh` verification gates before proposing integrations.

### 5. 🗺️ Cross-Device Project Atlas & Time Atlas Ingestion
- **Project Atlas:** Multi-repository scanner tracking live status, commits, branches, and dirty states across all active projects (`newton`, `work-atlas`, `gods-eye-view`, `macsync`, `fireclock`).
- **Time Atlas Phone Ingestion:** Native Swift zero-dependency protobuf (`.pb`) wire decoder ingesting daily physical activity, GPS moments, and journals synced to iCloud Drive from iPhone.
- **Cross-Device Idea Store:** Bi-directional Markdown/JSON idea sync across Mac and iPhone via iCloud Drive with SHA-256 deduplication.

## 🛠️ Build, Test & Shipping Protocol

- **Language & Runtime:** Swift 6, macOS 14+ deployment target, native Apple frameworks.
- **Zero Polling / 0% Idle CPU:** Event-driven architecture using `NSWorkspace` notifications, `ScreenCaptureKit` streams, and actor-isolated SQLite persistence.
- **Automated Verification:** `./test.sh` runs the complete test matrix (100+ Swift and Python tests).
- **Compilation & Packaging:** `./build.sh` produces `build/Newton.app` and `build/Newton.zip`.
- **1-Click Ship:** `./bin/ship.sh` auto-bumps the patch version, runs all regression tests, builds the binary, creates build receipts, mirrors to iCloud, and pushes commits + tags to GitHub in one deterministic pass.
